# crud-docker-app

A full-stack CRUD application built with Node.js and containerized using Docker.

## 🚀 Features
- Create, Read, Update, Delete operations
- User Authentication & Validation
- Statistics Dashboard
- Dockerized deployment

## 🛠️ Tech Stack
- **Backend**: Node.js, Express.js
- **Container**: Docker, Docker Compose
- **Deployment**: Railway

## ⚙️ How to Run

### With Docker
```bash
docker-compose up --build
```

### Without Docker
```bash
npm install
npm start
```
